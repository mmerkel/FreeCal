FreeCal's Calendar History as one line: Event Versions, Conflicts and Undo

The question. ADRs 0018 to 0020, as rewritten on 2026-11-22, replace the tree of Snapshots and its two pointers by one line of Snapshots across all Calendars. Each Event Version records the Snapshot it began with and the one it ended with; the user's Current-Version Mark is an empty end, the server's is stored. A Conflict ends at once with a Server Event Replacement and stays open until the user resolves it; an Undo is a Snapshot that takes back an earlier one. Does this hold when pushed through sends, the server's own form of a write, Incoming Syncs with Conflicts, Resolutions, undo and redo across Calendars, a server refusing writes, and dropping after 90 days? Where it doesn't, the walkthrough says Finding.

The Calendar History

One line of Snapshots of all Calendars, newest first. Each lists the Event Versions that end (−) and begin (+) with it. Any Snapshot can be undone from here, whole, a Server Intake or a Server Event Replacement too, but not a First Sync's. Ctrl+Z only reaches your own.

The Event Version table

Its content never changes: only end (once), begin (emptied when its Snapshot is dropped) and the server's mark.

The Resolution table

Written once per Server Event Replacement, never changed.
