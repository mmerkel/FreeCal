FreeCal's Calendar History: Event Versions, two pointers, merge and undo

The question. ADRs 0017 to 0020 replace the Change Journal, the Mirror, the Unsent Changes and the Conflict tables by one structure: Event Versions that never change, Snapshots, and a User's Pointer and a Server's Pointer per Calendar. Does that model hold when pushed through sends, Incoming Syncs, Conflicts and undo? Undo is a Snapshot that takes back an earlier one (grilling of 2026-11-21): Ctrl+Z reaches only your own changes, both pointers only move forward, and nothing from the server waits. And the point ADR 0019 left open: when the server stores FreeCal's own write in another form than was sent, how does the Snapshot that was sent take that form, given that Event Versions never change, also after an undo?
