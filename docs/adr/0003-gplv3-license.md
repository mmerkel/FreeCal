# GPLv3 license

FreeCal is licensed under GPLv3 or any later version (SPDX `GPL-3.0-or-later`), so it can also be used under a future GPL. Relicensing later needs every contributor's consent, so this is effectively permanent. Being fully GPLv3-compliant lets us use FullCalendar Premium plugins (timeline, print) for free should we need them. Every dependency must be GPLv3-compatible; MIT, BSD and Apache-2.0 all are.

`webpki-root-certs` (CDLA-Permissive-2.0, a data licence) comes in through ureq's `native-tls` feature, and we accept it. Its only condition is to ship its text with the data, and it puts no restrictions on what is built with the data, much like MIT. Its certificates also aren't in FreeCal's binary: the core uses the system's trusted certificates (`RootCerts::PlatformVerifier`), and the linker drops the bundled ones. No official list rules on its GPL compatibility: the FSF's list doesn't mention it, and Fedora's licence data marks it "allowed" (checked October 2026). ureq's `native-tls-no-default`, which would leave it out, panics on every `https://` request in ureq 3.4.
